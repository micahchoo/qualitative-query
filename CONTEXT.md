# Domain glossary

- **Question**: A saved request to find passages in the vault.
- **Passage**: An original block of text in a source note.
- **Local retrieval**: Finding candidate passages on the device through keywords and, when available, related wording.
- **Candidate**: A passage shortlisted for a question, before Jev checks whether it answers that question.
- **Selection**: The ordered passages shown for a question.
- **Saved selection**: A note containing source-linked passages in a fixed order. Passage text updates with its source.
- **Context**: Notes explicitly chosen to help Jev interpret a question.
